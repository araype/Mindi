Formularios (`m-field`, `m-input`, `m-check`): las listas de espera y la demo de Enterprise.

```jsx
<Field id="wl_name" label="Nombre" autoComplete="name" required />
<Check name="consent">Acepto la <a href="/privacidad">Política de privacidad</a>. Usaremos estos datos solo para contactarte sobre Mindi.</Check>
```

La etiqueta siempre se ve, nunca va solo como placeholder. Pide solo lo necesario. La casilla de consentimiento empieza sin marcar.
